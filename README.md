# Template Visual de Experiência Guiada

Projeto-fonte React/Vite com telas demonstrativas e fluxo de quiz totalmente local.

## Executar

```bash
npm install
npm run dev
```

## Gerar build

```bash
npm run build
npm run preview
```

## Rotas incluídas

- `/`
- `/como-funciona`
- `/escrever-carta`
- `/obrigado`
- `/ajuda-milena`
- `/apoio-milena`
- `/chamada-ao-vivo-milena`
- `/privacidade`
- `/termos`

O template não possui backend, integrações, coleta, rastreamento, pagamento, links externos ou persistência no navegador. Personalize textos legais, conteúdo e identidade antes de publicar.

O arquivo `public/_redirects` permite que hosts compatíveis abram diretamente qualquer rota da aplicação.
